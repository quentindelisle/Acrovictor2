# Acrovictor

PWA d’évaluation en acrosport (Situation 1 : 2 figures parmi 3) avec vidéo différée, chrono synchronisé, critères indispensables, pénalités, calcul du score (multiplicateur × nb d’étapes) et export Excel.

N’EPS by Quentin Delisle.

## Utilisation
1. **Classe** : importer un fichier Excel/CSV (colonne A = Nom, colonne B = Prénom).
2. **Groupes** : créer des groupes de 4 à 7 élèves (manuel, glisser-déposer ou aléatoire).
3. **Évaluer** : choisir groupe, figure, gymnastes et observateurs, puis activer la caméra.
4. **Résultats** : tableau par élève et par passage, export `.xlsx`, sauvegarde/restauration JSON.

La caméra nécessite HTTPS (GitHub Pages convient). Toutes les données restent sur l’appareil.
